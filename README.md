# 🎮 Tic-Tac-Toe Game in C

A simple, interactive, console-based Tic-Tac-Toe game developed using the C programming language.

## 📌 About the Project

This project is a two-player Tic-Tac-Toe game where players take turns marking spaces on a 3×3 grid. The objective is to get three identical symbols (X or O) in a horizontal, vertical, or diagonal row to win the game.

I developed this project to practice my C programming fundamentals and understand how game logic works.

## ✨ Features

- Two-player gameplay.
- Interactive 3×3 game board.
- Automatic win detection.
- Draw detection.
- Turn-based player switching.
- Simple console interface.

## 🛠️ Technologies Used

- **Programming Language:** C
- **IDE:** Code::Blocks
- **Platform:** Windows

## 🎯 How to Play

1. Download the `TicTacToe.exe` file from this repository.
2. Run the executable on a Windows computer.
3. Two players take turns entering their moves.
4. Player 1 uses X and Player 2 uses O.
5. The first player to get three symbols in a row wins.
6. If all spaces are filled without a winner, the game ends in a draw.
